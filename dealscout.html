Developer notes · connect an authorized live data source

Default: this file is self-contained and uses clearly labeled illustrative sample offers. It does not contact retailers, infer a user's location, scrape websites, or collect personal information. The ZIP code is used only for the search submitted in this page.

To connect live data: provide a backend endpoint you control, then set API_BASE_URL near the top of the script. The page will request GET /api/nearby-deals?zip=92501&radius=25. Keep provider credentials on your server, not in this HTML file. Use a retailer-approved integration or a data provider whose access and permitted use you have verified. The endpoint must allow this page's origin through its CORS policy (or be hosted on the same origin).

Expected response shape: live deal cards are displayed only when each deal has a verified, authorized source. Home Depot penny rows have stricter checks: retailer must be The Home Depot, price must be exactly 0.01, and both source.authorized and source.verified must be true. Aisle/bay is displayed only when locationVerified is true.
